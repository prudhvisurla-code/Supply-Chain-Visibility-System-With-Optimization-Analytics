# Supply Chain Analytics – Milestone 3

## Supplier Performance & Transportation Analytics using Power BI

A Power BI dashboard focused on evaluating supplier performance and transportation efficiency through supplier scorecards, cost analysis, carrier performance, and route benchmarking.

---

# Project Overview

This project analyzes supplier and transportation performance using Power BI. It provides insights into supplier quality, delivery reliability, transportation costs, and carrier efficiency for better supply chain decisions.

# Methodologies

## Supplier Scorecard Calculation Methodology

The supplier scorecard is calculated using:
- Product Quality
- On-Time Delivery Performance
- Lead Time
- Procurement Cost

These metrics are combined to generate an overall supplier performance score.

## Supplier Ranking & Benchmarking Approach

Suppliers are ranked based on their overall score. Benchmarking compares supplier performance against average values to identify top, average, and low-performing suppliers.

## Transportation Cost Analysis Methodology

Transportation costs are analyzed by evaluating:
- Shipping Mode
- Carrier
- Transportation Route
- Total Freight Cost

This helps identify cost-saving opportunities.

## Route & Carrier Performance Evaluation

Performance is evaluated using:
- Delivery Time
- Freight Cost
- Shipping Mode Performance
- Carrier Efficiency
- Route Effectiveness
